# Forecast Model Artifacts

Forecast model artifacts are generated locally and are not required to run the
API. The prediction service uses a trained artifact when available; otherwise,
the application forecast route uses an available provider or explicitly
simulated carbon forecast. Unavailable or invalid inputs are reported as
unavailable rather than represented as provider data.

Training data is generated by the repository's synthetic zone simulation; it
is not a collected historical provider dataset. Training writes:

- `best_model.pkl` — serialized selected model and metadata.
- `training_report.json` — training metrics and run metadata.

From the `backend/` directory, train using the installed backend environment:

```powershell
python forecast/train.py
```

Training can take substantial time and writes/overwrites these local artifacts.
Do not interpret model outputs or training metrics as measured future carbon
intensity or verified environmental impact.
